# 🎓 Personalized Learning & Recommendation System

A full-stack personalized learning and recommendation system that provides customized learning suggestions based on student performance data using a Python-based Machine Learning model.

## ✨ Features

* 🔐 Secure role-based authentication
* 👨‍🎓 Student and Faculty dashboards
* 🤖 Personalized learning recommendations
* 📊 Student performance tracking
* 📈 Progress monitoring and analytics
* 📑 Report generation
* 🗄️ MySQL database integration

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Machine Learning:** Python, Machine Learning
* **Tools:** XAMPP, Jupyter Notebook

## ⚙️ How It Works

1. Students provide their performance-related information.
2. The system stores student data in the MySQL database.
3. A Python-based Machine Learning model processes the performance data.
4. The model generates personalized learning suggestions.
5. Students can view their recommendations and track their progress.
6. Faculty can monitor student performance through the dashboard.

## 🎯 Key Highlights

* Developed a complete full-stack personalized learning platform.
* Integrated a Python-based ML model with the web application.
* Implemented role-based authentication for students and faculty.
* Developed dashboards for performance tracking and analytics.
* Added report generation and progress monitoring functionality.
